Task 1.

In my previous job, there was an Access program that calculated products manufactured by the company I worked for. This program also generated XML files that were imported to three company websites and the product price list in Bitrix24. The person who developed this software stopped supporting it. Due to legislative changes, it was necessary to add "TU," which are certain specified letters and numbers, to the names of all products. In short, you needed to take the price list, concatenate the columns “Name,” “Label,” and “Numeric Label,” and write it all back into “Name.” Since I had wanted to try out some Python libraries that handle user interactions for a while, I used PySimpleGUI to organize the form, loaded the price list from XML using pandas, modified it, and wrote it back into XML. Then, using auto-py-to-exe, I converted the script into an exe so it could run on any PC with Windows. It turned out great, as long as you have the right price list :-)
